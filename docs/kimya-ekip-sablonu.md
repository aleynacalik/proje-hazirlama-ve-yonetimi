# Ekip veri şablonu – Kimya

| Bilgi | Değer |
|---|---|
| Kimyasal reaksiyon | Aspergillus niger ile glukozdan sitrik asit üretimi |
| Net reaksiyon | C6H12O6 + 1.5 O2 → C6H8O7 + 2 H2O |
| İdeal sıcaklık aralığı | 28–32 °C (demo) |
| Optimum sıcaklık | 30 °C |
| Kritik sıcaklık alt/üst | 25 / 37 °C (demo) |
| İdeal pH aralığı | 2,0–3,0 (üretim evresi; demo) |
| Optimum pH | 2,5 (model hedefi) |
| Kritik pH alt/üst | 1,5 / 4,0 (demo) |
| Teorik maksimum verim | %100 teorik dönüşüm esasına göre yaklaşık 1,067 g sitrik asit/g glukoz |
| Panel baz verimi | %80 (teorik maksimuma göre demo hedefi) |
| Sıcaklık/pH etkisi | Düşük sıcaklık reaksiyon hızını, yüksek sıcaklık enzim faaliyetini olumsuz etkileyebilir. Düşük üretim pH'ı yan ürünleri baskılayabilir; etkiler suşa bağlıdır. |
| Kaynaklar | https://doi.org/10.1016/j.biortech.2020.124426 ; https://doi.org/10.1093/jimb/kuaf007 ; https://doi.org/10.1186/s12934-019-1064-6 |

Ayrıntılı açıklama: [Kimya proses notu](kimya-proses-notu.md). Kritik sınırlar eğitim amaçlı alarm eşikleridir, tesis güvenlik sınırı değildir. Matematik ekibi katsayıları ve EEM ekibi alarm gecikmesini belirler.
